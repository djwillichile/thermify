# Global climate models of the WorldClim 2.1 CMIP6 projections

Names of the CMIP6 global climate models distributed by WorldClim 2.1 at
30 arc-seconds (checked on 2026-11-20 for SSP2-4.5, 2041-2060). Not
every model provides every scenario or period.

## Usage

``` r
worldclim_cmip6_gcms
```

## Format

A character vector.
